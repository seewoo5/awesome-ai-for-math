# awesome-ai-for-math

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)


A curated list of 3025 awesome papers exploring the use of artificial intelligence / machine learning / deep learning for mathematical discoveries.

**[Interactive page](https://seewoo5.github.io/awesome-ai-for-math/)**: search, filter by subject or year, and explore papers-by-year charts.

## Tags

Each paper has subject tags (e.g. `Number Theory`, `Combinatorics`) and method tags (e.g. `RL`, `Transformer`, `ATP`). Papers using LLMs carry exactly one LLM tag:

- `LLM (major)`: the core results were essentially produced by AI; the authors mainly posed the problem, verified, and wrote it up.
- `LLM (minor)`: humans drove the research, but AI proved nontrivial lemmas or intermediate steps, supplied key ideas or constructions for part of the argument, or wrote the formal (e.g. Lean) proofs.
- `LLM (tool)`: papers about LLMs for mathematics with no AI-attributed new result (benchmarks, surveys, prover systems).

Papers that used AI only for proofreading, grammar, literature search, or finding minor errors are not included.

## Contributing

Add a row to the table in [`papers.md`](papers.md) and open a pull request. See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the row format and tagging rules.

Only papers posted on [arXiv](https://arxiv.org) or published in peer-reviewed venues are considered. Papers hosted only on other websites or in self-hosted GitHub repositories are not included.

With the rapid growth in the number of AI-assisted papers, I'm still figuring out the best way to collect them. Suggestions are welcome; please [open an issue](https://github.com/seewoo5/awesome-ai-for-math/issues).
